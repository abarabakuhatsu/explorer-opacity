# 6. ログ出力の設定化（無効化・保存先指定）と既定を exe 隣へ変更

* ステータス: 承認
* 日付: 2026-10-01
* 決定者: ユーザー + AIエージェント

## コンテキスト（背景）
従来ログは `%LOCALAPPDATA%\explorer-opacity\explorer-opacity.log` に固定で出力していた。
これはポータブル方針（設定は exe 隣）と一貫せず、ログを無効化する手段も無かった。

## 決定事項（Decision）
`[logging]` セクションを追加する。

```toml
[logging]
enabled = true
path = ""
```

- `enabled = false` でログを完全に無効化する（ファイルも生成しない）。
- `path` 未指定（空）の既定は **exe と同じフォルダ** の `explorer-opacity.log` とする。
- `path` の解釈:
  - 相対パスは exe フォルダ起点
  - `%VAR%` を環境変数展開（未知はそのまま）
  - 末尾 `\` `/` または既存ディレクトリはディレクトリ扱いで `explorer-opacity.log` を付加
  - それ以外はファイルパスとして使用
- ロガーは `OnceLock` から `Mutex<LogState>` に変更し、**設定リロード時に再構成**できるように
  する。無効時は `write` を no-op にする。
- ログ無効時はトレイの「Open log」項目を表示しない。

## 影響・結果（Consequences）
### ポジティブな影響
- ログの有無と保存先をユーザーが制御できる。
- 設定・ログともに既定が exe 隣になり、ポータブル方針が一貫する。
- リロードでログ設定変更を即時反映できる。

### ネガティブな影響・トレードオフ
- 既定のログ出力先が変わる（旧 `%LOCALAPPDATA%` から exe 隣へ）。旧ファイルは残置される。
- exe が書き込み不可の場所にあると、既定ではログが保存されない（書き込み失敗時は本体動作を
  継続）。
- 環境変数展開のため、パスに `%` を含めたい場合は未定義変数として残る挙動を理解する必要がある。
